1.1 Core Thesis & Architecture of the Base Paper

The base paper proposes Blended RAG to solve the primary accuracy bottleneck in Retrieval-Augmented Generation: retrievers feeding irrelevant or incomplete context to the Generator LLM. Instead of relying on a single retrieval modality, the authors blend three complementary index families across structured document fields (title and abstract/body):

1. BM25 (Lexical)
Exact keyword & token frequency matching across fields. High precision on unique scientific names, entity IDs, and precise terms.
2. Dense KNN (Vectors)
Sentence transformer embeddings in vector space (FAISS). Captures abstract semantic intent and conceptual similarity.
3. Sparse Encoders
SPLADE / ELSER learned sparse expansions. Matches query terms to expanded vocabulary concepts while preserving interpretability.

1.2 Multi-Field Querying & 3-Way Reciprocal Rank Fusion (RRF)

Sawarkar et al. demonstrated that searching structured fields separately (Best Fields: taking the maximum score across Title and Text) beats flat concatenated text. All three retriever rankings are combined using Reciprocal Rank Fusion (RRF) with smoothing parameter $k=60$:

Score_RRF(d) = Σ_{m ∈ {BM25, Dense, SPLADE}} [ 1 / (60 + Rank_m(d)) ] Best-Fields Rule: Score_BM25(Q, d) = max( Score_title(Q, d), Score_abstract(Q, d) )

3.1 Cascaded Sequential Architecture

Instead of executing all three retrievers statically, our proposed extension introduces a sequential confidence gate at Tier 1. Simple factual queries exit immediately; difficult queries escalate to Blended RAG:

[Incoming Query Q] │ ▼ [Tier 1: Fast-Pass BM25 Best Fields] ───> Cost: ~10 ms (CPU) │ ├───> Extract Scores: s1 (Top-1), s2 (Top-2), Margin Δ = (s1 - s2) │ ╱ ╲ IS (s1 ≥ τ_high) OR (Δ ≥ τ_gap AND MaxIDF ≥ τ_idf) ? ╱ ╲ YES NO ╱ ╲ ▼ ▼ [EARLY EXIT: Tier 1] [TIER 2: ESCALATE TO BLENDED RAG] Return BM25 Top-K 1. Dense MiniLM (FAISS) Savings: 100% Neural Skipped 2. SPLADE Sparse Expansion Latency: ~10 ms (85% Faster) 3. 3-Way Reciprocal Rank Fusion (RRF)

3.2 Mathematical Decision Gating Rules

The decision function $\text{Route}(Q)$ is calibrated using 5-fold cross-validation to prevent data leakage:

Route(Q) = EarlyExit (Tier 1) if s1 ≥ τ_high ∨ ( (s1 - s2) ≥ τ_gap ∧ MaxIDF(Q) ≥ τ_idf ) Route(Q) = BlendedRAG (Tier 2) otherwise
