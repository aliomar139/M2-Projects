## Psychometric Scoring & Target Feature Engineering Protocol

### 1. Reverse Scoring Academic Efficacy
$$\text{MBI\_PE\_1\_REV} = 6 - \text{MBI\_PE\_1}$$
$$\text{MBI\_PE\_2\_REV} = 6 - \text{MBI\_PE\_2}$$
$$\text{MBI\_PE\_3\_REV} = 6 - \text{MBI\_PE\_3}$$

### 2. MBI-SS Subscale Means
$$\text{EE\_Mean} = \frac{\text{MBI\_EE\_1} + \text{MBI\_EE\_2} + \text{MBI\_EE\_3}}{3}$$
$$\text{CY\_Mean} = \frac{\text{MBI\_CY\_1} + \text{MBI\_CY\_2} + \text{MBI\_CY\_3}}{3}$$
$$\text{PE\_REV\_Mean} = \frac{\text{MBI\_PE\_1\_REV} + \text{MBI\_PE\_2\_REV} + \text{MBI\_PE\_3\_REV}}{3}$$

### 3. Composite Academic Burnout Index
$$\text{Burnout\_Index} = \frac{\text{EE\_Mean} + \text{CY\_Mean} + \text{PE\_REV\_Mean}}{3}$$

### 4. Target Classification Stratification (Target Label $y$)
* **Class 0 (Low Burnout Risk):** $\text{Burnout\_Index} < 2.50$
* **Class 1 (Moderate Burnout Risk):** $2.50 \le \text{Burnout\_Index} \le 3.60$
* **Class 2 (High Burnout Risk - Target Minority):** $\text{Burnout\_Index} > 3.60$

### 5. Engineered Predictor Features ($X$)
* **GenAI Dependence Index:**
  $$\text{GenAI\_Dependence\_Index} = \left(\frac{\text{AI\_COG} + \text{AI\_CRIT} + \text{AI\_DEL} + \text{AI\_EXAM}}{4}\right) \times \left(\frac{\text{AI\_FREQ}}{5.0}\right)$$
* **Verification Deficit:**
  $$\text{AI\_Verif\_Deficit} = 6 - \text{AI\_VERIF}$$
* **Coping Disparity Ratio:**
  $$\text{Coping\_Disparity\_Ratio} = \frac{\text{COP\_AVOID\_1} + \text{COP\_AVOID\_2}}{\text{COP\_ACT\_1} + \text{COP\_ACT\_2} + 0.1}$$
* **Infrastructure Disruption Index:**
  $$\text{Infra\_Disruption\_Index} = \text{INF\_ELEC} + (6 - \text{INF\_NET}) + \text{INF\_FIN}$$
