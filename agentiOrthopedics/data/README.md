# Supporting data and evidence

Most day-to-day reading belongs in [LR](../LR/README.md). This folder preserves the evidence behind the deliverables.

| Folder/file | Contents |
|---|---|
| `reviews/` | Latest search logs, candidates, triage labels, novelty checks and PRISMA/library counts |
| `audit/` | Initial 100-paper audit tables, extracted PDF text, Crossref metadata, original XML and additional anchors |
| `searches/initial/` | Early exploratory exports and the ranked 100-citation dataset |
| `searches/first_pass/` | Raw responses for queries P1-P4 |
| `searches/reviews/` | Raw responses for the added review searches R1-R3 |
| `searches/novelty/` | Raw responses for the seven candidate-dimension checks |
| [maintenance](maintenance/README.md) | Reorganization log and validation results |
| `source_aliases.json` | Maps earlier paths and removed duplicate copies to their surviving source |

The current dimension tables and review registry remain in [LR/Surveys](../LR/Surveys/README.md), beside their readable interpretation. No search was rerun as part of the cleanup, and the recorded search dates/cutoffs remain unchanged.

Retain raw exports and audit evidence when editing a report. A search result, an available file and a final included study are different counts.
