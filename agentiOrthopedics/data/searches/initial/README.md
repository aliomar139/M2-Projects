# Archived Datasets

This directory contains exploratory literature search datasets collected during the initial scoping and scoping phase of the research:

- **`AgenticAi.csv`**: Raw search export capturing literature on agentic AI workflows, autonomous clinical agents, and intelligent decision systems in medicine.
- **`CrossDomain.csv`**: Raw search export capturing cross-domain individualized treatment recommendation (ITR) systems, survival-guided clinical recommendation engines, and related biomedical reinforcement learning frameworks.

---

### Master Dataset
Both search corpora were curated, filtered, deduplicated, and ranked into the final active project dataset:
- [Ranked 100-citation export](top_100_orthopedic_ai_papers.csv). This is a historical export; consult the [current source index](../../../papers/corpus/README.md) before interpreting its verification claims.
