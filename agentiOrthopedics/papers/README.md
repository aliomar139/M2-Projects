# Paper sources

[Open the 100-citation index](corpus/README.md) to find papers from the earlier collection. The index distinguishes original main text, supplementary files, generated summaries and wrong-document records.

Review papers used in the current deliverables live in [LR/Surveys](../LR/Surveys/README.md). A byte-identical paper is stored once; both indexes point to that copy.

`corpus/manifest.csv` is the original download manifest. Its filenames and status fields describe the earlier collection and are not a current verification record. Use `corpus/catalog.csv` for current source locations. Generated summary PDFs and wrong documents are preserved in [archive](../archive/README.md), with their audit classifications intact.
